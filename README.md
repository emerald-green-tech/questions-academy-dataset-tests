# Questions Academy Dataset Tests #

This repository contains tests for the datasets of questions used on the [Questions Academy]. The questions themselves
are in separate repositories, the names of which start with `questions-academy-dataset-`, for example:

*   [questions-academy-dataset-opentriviaqa]
*   [questions-academy-dataset-questions-academy]



Schema validation tests for Questions Academy datasets.

## Usage ##


```
pytest --log-cli-level INFO
pytest --log-cli-level DEBUG
```
